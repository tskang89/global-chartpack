# 글로벌 차트팩

<https://tskang89.github.io/global-chartpack/>

조간 브리핑 참고자료에 걸리는 쪽이다. **나라에 묶이지 않는 지표**만 모은다 —
원자재, 국가를 넘나드는 시장 변수. 나라별 거시지표는
[주요국 경제 차트팩](https://github.com/tskang89/euro-chartpack)이 맡는다.
두 쪽이 겹치면 어느 쪽을 봐야 할지 알 수 없게 된다.

평일 날마다 돈다. 시장 자료라 매일 움직인다.

## 무엇이 들어 있나

| 묶음 | 지표 |
|---|---|
| 원자재 | 금 · 은 · 구리 · 브렌트 · WTI · 두바이 · TTF · 헨리허브 · S&P GSCI 종합 · FAO 식량/곡물 |
| 금리 | 미국·독일·일본 10년물 · SOFR · 유리보 1·3·6·12개월 |
| 환율·리스크 | 달러인덱스 · VIX |

## 축이 둘이다

시장 자료는 일별인데 몇몇은 월별로만 나온다.

| | |
|---|---|
| 일별 (약 2년) | 선물·지수·금리 대부분 |
| 월별 (60개월) | 두바이유(ECOS)·FAO 지수·유리보(ECB 가 월평균만 공표) |

월별 값을 일별 축에 늘어놓으면 계단이 되어 '한 달 내내 값이 같았다'로 읽힌다.
그래서 따로 그리고, 그림 제목 밑에 일별인지 월별인지 적는다.

## 넣지 못한 둘

**발틱운임지수(BDI)** — 발틱거래소가 라이선스로 묶어 두어 공개 계열이 없다
(발틱거래소·한국해양진흥공사·KMI 모두 막힘, 2026-10-06 확인). Yahoo 의 `BDRY`
는 건화물 운임 **선물 ETF** 라 지수가 아니다. 대용물을 'BDI' 라는 이름으로
올리면 읽는 사람을 속이게 되므로 뺐다.

**S&P GSCI 농산물지수** — 공개 창구에 과거치가 하루치만 있어 선을 그릴 수 없다.
같은 자리에 FAO 곡물지수를 두었다.

## 돌리기

```
pip install -r requirements.txt
ECOS_API_KEY=... python build/make.py          # index.html 을 새로 쓴다
ECOS_API_KEY=... python build/make.py --check  # 쓰지 않고 만들어만 본다
```

`ECOS_API_KEY` 는 두바이유에만 쓴다. 없으면 그 그림만 빠지고 나머지는 올라간다.

## 짜임

```
build/fetchers.py  출처별 받아오기 (Yahoo·분데스방크·재무성·뉴욕연준·ECB·ECOS·FAO)
build/sources.py   무엇을 받아 어떻게 묶을지 · 값 점검 범위
build/make.py      축 맞추기 · 쪽 만들기
template.html      틀 (차트 엔진은 주요국 경제 차트팩과 같은 것)
```

차트 엔진(Chart.js + 값 이름표 플러그인)은 주요국 경제 차트팩에서 그대로
가져왔다. 두 쪽의 그림이 달라 보이면 같은 사무소에서 나온 것으로 읽히지 않는다.

한 지표가 실패해도 나머지는 올라가고, 빠진 것은 화면에 적는다.
